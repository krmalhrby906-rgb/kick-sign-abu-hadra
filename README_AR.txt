MOD STREAM APP PRO — NETLIFY
================================

النسخة الجديدة:
- واجهة تشبه برنامج/لوحة تحكم.
- المود يكتب اسمه وPIN.
- حضور / خروج.
- ترتيب أسبوعي.
- الموجودون الآن.
- Logs خاصة بالإدارة.
- الإدارة تضع اسم البث + رابط البث + المنصة.
- عند بدء البث يظهر للمودات كرت LIVE وزر "مشاهدة البث".
- البيانات محفوظة أونلاين باستخدام Netlify Blobs.

الرفع:
1) فك الضغط.
2) ارفع مجلد mod-stream-app-pro كامل إلى Netlify.
3) بعد النشر أرسل رابط netlify.app للمودات.

6868

لتغييره:
Netlify > Project configuration > Environment variables
ADMIN_PIN = الكود الجديد

الهدف الأسبوعي الافتراضي:
60
ولتغييره:
