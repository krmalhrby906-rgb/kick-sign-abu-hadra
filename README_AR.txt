MOD STREAM — NETLIFY
=====================

هذه النسخة مخصصة لـ Netlify وتحفظ البيانات واللوقات أونلاين باستخدام Netlify Blobs.

أسهل طريقة للرفع:
1) فك ضغط الملف.
2) سجل دخولك في Netlify.
3) افتح صفحة Deploy manually / Drop.
4) اسحب مجلد mod-stream-netlify كامل إلى Drop zone.
5) انتظر انتهاء البناء.
6) افتح الرابط الذي يعطيك Netlify وأرسله للمودات.

كود الإدارة الافتراضي:
6868

لتغيير كود الإدارة بعد الرفع:
Project configuration > Environment variables
أضف:
ADMIN_PIN = الكود الجديد
ثم اعمل Redeploy.

الحد الأسبوعي الافتراضي:
60 نقطة
يمكن تغييره بمتغير:
WEEKLY_TARGET = 60

الاستخدام:
- الإدارة > اكتب 6868
- أضف اسم كل مود + PIN خاص به
- ابدأ البث
- المود يكتب اسمه + PIN ويضغط دخول
- عند خروجه يكتب اسمه + PIN ويضغط خروج
- اللوقات لا تظهر للعامة، فقط بعد دخول الإدارة
- يوجد زر لتصفير نقاط الأسبوع
